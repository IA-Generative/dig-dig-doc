# Consulter et partager les résultats

## Consulter les synthèses

Chaque dossier dispose d'une **synthèse** générée par l'IA :

1. Ouvrez le dossier.
2. La synthèse s'affiche en haut de page, avec les informations clés
   extraites et les éventuelles alertes (incohérences, documents manquants).
3. Vous pouvez **éditer** la synthèse pour ajouter vos propres annotations.

## Partager un dossier

Vous pouvez partager un dossier avec un autre utilisateur de la plateforme :

1. Ouvrez le dossier à partager.
2. Cliquez sur le bouton **Partager**.
3. Saisissez l'identifiant ou l'email du destinataire.
4. Choisissez le niveau d'accès :
   - **Lecture** : consultation uniquement.
   - **Édition** : modification des documents et des résultats.
5. Validez : le destinataire recevra une notification.

## Dossier éphémère

Pour partager un dossier sans création de compte ou pour une révision
rapide, vous pouvez générer un **lien éphémère** :

1. Ouvrez le dossier.
2. Cliquez sur **Partager** → **Lien éphémère**.
3. Le lien généré est valable pendant une durée limitée.
4. Partagez ce lien : le destinataire peut consulter le dossier sans
   authentification.

> **Important** : les liens éphémères expirent automatiquement. Pour un
> accès permanent, préférez le partage nominatif.
