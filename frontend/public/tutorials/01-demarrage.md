# Démarrage : créer une analyse et un dossier

## 1. Créer une analyse

Une **analyse** définit le type de traitement IA appliqué à vos documents
(classification, extraction d'entités, etc.).

1. Dans la barre latérale, cliquez sur **Analyses**.
2. Cliquez sur le bouton **Créer une analyse**.
3. Renseignez un nom et sélectionnez le type d'analyse souhaité.
4. Validez : l'analyse apparaît dans la liste.

## 2. Créer un dossier

Un **dossier** regroupe les documents d'un usager ou d'une demande.

1. Dans la barre latérale, cliquez sur **Dossiers**.
2. Cliquez sur **Créer un dossier**.
3. Donnez un nom au dossier (ex. « Demande de titre de séjour — M. Dupont »).
4. Validez : le dossier est créé et prêt à recevoir des documents.

> **Astuce** : si vous ne savez pas quelle analyse rattacher à votre dossier,
> cochez « Dossier à ranger ». L'IA vous suggérera automatiquement une analyse
> pertinente à partir du contenu des documents importés.
