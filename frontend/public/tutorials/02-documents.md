# Ajouter des documents à un dossier

## Importer des fichiers

1. Ouvrez le dossier auquel vous souhaitez ajouter des documents.
2. Cliquez sur la zone **Déposer des fichiers** ou glissez-déposez
   directement vos documents dans la zone pointillée.
3. Les formats acceptés sont : **PDF**, images (PNG, JPG), tableurs (CSV, XLSX).
4. Chaque document est téléversé et apparaît dans la liste des pièces du dossier.

## Organiser les pièces

- Vous pouvez **renommer** un document en cliquant sur son titre.
- L'**ordre** des pièces peut être réorganisé par glisser-déposer.
- Le **type de pièce** (CNI, justificatif, etc.) est détecté automatiquement
  par l'IA lors de l'analyse, mais vous pouvez le corriger manuellement.

> **Note** : la taille maximale par fichier est de 50 Mo. Pour les PDF de
> plusieurs dizaines de pages, le traitement peut prendre quelques dizaines
> de secondes.
