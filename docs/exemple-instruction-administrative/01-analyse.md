# Analyse

## Nom

Instruction d'une demande d'aide au logement

## Description

Vérifie qu'un dossier de demande d'aide exceptionnelle au logement est complet et cohérent, extrait les informations utiles à l'instruction (identité, adresse, ressources, loyer, coordonnées bancaires) et prépare une synthèse pour l'instructeur. La décision d'accord ou de refus reste prise par une personne.

## Contexte métier

Le demandeur dépose : le formulaire de demande, une pièce d'identité, un justificatif de domicile de moins de 3 mois, le dernier avis d'imposition, un RIB et le bail.

L'aide est accordée sous condition de ressources et de résidence dans la commune. Le montant demandé ne dépasse pas 3 mois de loyer.
